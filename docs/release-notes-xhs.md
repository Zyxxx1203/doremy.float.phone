# 更新说明 · 小红书发布版

> 用法：直接复制正文发笔记；图片建议配 3 张——一起看播放界面、观看记录的「接着看」卡片、生活时钟滑条。

📱 我的AI虚拟手机又更新了！这次全是大件

上次发的版本过了一阵子，这几天把三个核心App都翻新了一遍，还修了一堆积压的老毛病，逐条说👇

🎬 一起看（变化最大）

· 不用再折腾Termux了！解析器直接内置进网页：小红书链接（包括xhslink短链）扔进去就能解析→下载→播放，全程零配置
· B站短链接b23.tv自动换算成真实视频，不再出现顶栏遮挡、画面卡第一帧
· 看过的视频永久缓存：下次打开同一链接秒开，还会自动跳回上次进度——长剧可以慢慢追
· 缓存管理搬进了「观看记录」：每条记录显示缓存大小，可以单条删，也能一键清空
· 「标记重点」重做：看片途中点一下，角色直接就这个时间点跟你聊，不用再自己打字
· 解析完的视频可以截帧喂给AI看画面了（之前被跨域限制锁死）

🌇 生活

· 时钟控制区终于能打开了！之前时间流速滑条、+1虚拟小时这些功能写了但永远显示不出来
· 沉浸场景里的提示不再消失：角色在睡觉没被叫醒时会有明确提示，不再像卡死

🖼 照片墙

· 底部导航加了「全部记忆」入口（之前这个页面做好了但没有门）
· 批量上传照片会落在你当前看到的位置，不再跑到画面外
· 每日自动生成尊重你选的角色，失败也不再反复重试烧API

⚙️ 全局体验

· 安卓返回键不再误杀整个App（之前看着看着按返回直接退出去）
· 「通话统计」正式内置进手机，聊天数据直读，不用单独安装
· 修了一波存量bug：行程地点写入地点库的转义错误、照片墙画布背景与导出不一致等

🛠 给二开的朋友

· 构建期类型检查重新打开（全仓tsc零错误），类型回归会被build直接拦下
· 清理了弹幕、横屏模式等一堆死代码，watch-together主文件瘦身
· 新增scripts/sync-to-public.mjs：实验仓库→公开仓库一键同步

⚠️ 桌面小组件现已加入按 profileId 区分实例的数据存储逻辑；仍建议在 Android 桌面上实测连续添加两个实例，确认各自内容独立。
